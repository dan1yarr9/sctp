Python 3.10+ | Google OR-Tools | Optimality Gap | License: MIT

Қолданбалы математика және математикалық модельдеу жобасы (Атырау, 2026)  
Мектеп курсының сабақ кестесін құру есебін (School Course Timetabling Problem, SCTP — NP-hard) СанҚмН нормалары, оқушылардың тәуліктік-апталық биоритмдері және нақты психометриялық деректер негізінде дискретті оңтайландыру кешені.

## Зерттеудің өзектілігі мен ғылыми жаңалығы

Мектеп кестесін қолмен немесе қарапайым эвристикамен құру кезінде жүздеген ресурстық шектеулерді бір мезгілде қанағаттандыру мүмкін болмағандықтан, оқушылардың когнитивті шаршауы ескерусіз қалады.

Жұмыстың жаңалығы:

1. **Норматив пен психометрия синтезі:** ҚР ДСМ-76 СанҚмН қиындық балдары мен 207 оқушының эмпирикалық сауалнамасы бірыңғай мақсатты функцияға біріктірілді ($\alpha\text{-Кронбах} = 0.9057$).
2. **Дәл математикалық аппарат:** Эвристикалық жақындаулардың орнына Google OR-Tools CP-SAT (Lazy Clause Generation) және MILP шешкіштері арқылы жаһандық оптимум сандық түрде дәлелденді ($\text{Gap} = 0.00\%$).

## Математикалық модельдің қысқаша формализациясы

### Айнымалылар

* $x_{c,s,d,p} \in \{0, 1\}$ — $c$ сыныбына $d$ күні $p$ сабағына $s$ пәнінің қойылуы (2205 айнымалы).
* $y_{c,d} \ge 0, \; y_{c,d} \in \mathbb{Z}$ — күндік жүктеменің нормативтік идеалдан ауытқу модулі (15 айнымалы).
* $z_{c,d,p} \in \{0, 1\}$ — $p$ және $p+1$ слотында қатар келген күрделі пәндер ($S_{hard}$) индикаторы (90 айнымалы).

### Қатаң шектеулер (Hard Constraints)

1. **Слоттың бірегейлігі:**  
   $$\sum_{s \in S} x_{c,s,d,p} \le 1 \quad \forall c, d, p$$
2. **Оқу жоспарын толық орындау:**  
   $$\sum_{d \in D} \sum_{p \in P} x_{c,s,d,p} = h_{c,s} \quad \forall c, s$$
3. **Кабинеттер қорының лимиті:**  
   $$\sum_{c \in C} x_{c,s,d,p} \le R_s \quad \forall s \in S_{special}, d, p$$
4. **Терезелерді болдырмау:**  
   $$\sum_{s} x_{c,s,d,p} \le \sum_{s} x_{c,s,d,p-1} \quad \forall c, d, p \ge 2$$
5. **Күндік қайталану мен ауыр пәндер лимиті:**  
   $$\sum_{p} x_{c,s,d,p} \le N_{max}(s), \quad \sum_{s \in S_{hard}} \sum_{p} x_{c,s,d,p} \le H_{max}(c)$$
6. **Бекітілген слоттар:**  
   $$x_{c, s_0, 1, 1} = 1$$  
   (Сынып сағаттары мен спецкурстарды қатаң байлау).

### Мақсатты функция (Multi-Objective Function)

$$\min \quad \Phi = \alpha_1 \sum_{c \in C, d \in D} y_{c,d} + \alpha_2 \sum_{c,s,d,p} M_p \cdot L_s \cdot x_{c,s,d,p} + \alpha_3 \sum_{c,d,p} z_{c,d,p}$$

* **Линеаризация шарттары:**  
  $$y_{c,d} \ge \Lambda \sum_{s,p} L_s x_{c,s,d,p} - I_{c,d}, \qquad y_{c,d} \ge I_{c,d} - \Lambda \sum_{s,p} L_s x_{c,s,d,p}$$  
  $$z_{c,d,p} \ge \sum_{s \in S_{hard}} x_{c,s,d,p} + \sum_{s \in S_{hard}} x_{c,s,d,p+1} - 1 \quad \forall c, d, p < 7$$

## Психометриялық калибрлеу ($N = 207, \; \alpha = 0.9057$)

Сауалнаманың орташа балы ($\bar{a}_i$) арқылы салмақтар бірлік масштабқа келтірілді: $\hat{w}_i = (\bar{a}_i - 1)/4$.

* **Калибрленген апталық идеал вектор:**  
  $$\mathbf{\tilde{K}_d = [13\%, 27\%, 27\%, 20\%, 13\%]}$$  
  (дүйсенбі/жұма жеңілдетілген, сәрсенбі пик).
* **Слоттардың шаршау мультипликаторлары:**  
  $$M_p = [0, 0, 0, 16, 16, 33, 33]$$  
  (6–7 сабақтарға ауыр сабақтар қойылса айыппұл салынады).
* **Масштабталған салмақтар:**  
  $$\alpha_1 = 1081, \; \alpha_2 = 100, \; \alpha_3 = 43418$$  
  (өлшем бірліктерін автоматты теңестіру ережесі арқылы).

## Орнату және іске қосу

### 1. Талаптар

* Python 3.10 немесе одан жоғары
* 64-биттік ОЖ (Linux, macOS, Windows)

### 2. Клондау және кітапханаларды орнату

```bash
git clone [https://github.com/dan1yarr9/sctp.git](https://github.com/dan1yarr9/sctp.git)
cd sctp
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt

```

### 3. Оңтайландыруды бастау

```bash
python main.py

```

Есептеу аяқталған соң `output/` каталогында генерацияланады:

* `output/schedule.xlsx` — сыныптар бойынша оңтайландырылған сабақ кестесі.
* `output/results.csv` — CP-SAT пен MILP салыстырмалы көрсеткіштері мен метрикалары.
* `output/survey_summary.csv` — психометриялық өңдеу нәтижелері (SEM, t-статистика, p-value).
